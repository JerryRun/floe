## 本次更新

- 会话右键菜单支持复制 IP 或主机地址。
- 文件预览支持 PDF，可翻页、跳转、缩放及适应宽度，并保留独立窗口和工作区面板两种查看方式。
- 文本、图片、视频和 PDF 预览支持刷新重新载入；文本有未保存修改时先确认，HLS 刷新会重新加载播放列表与分片。
- 新增开发工具箱，支持全屏展开，并在切换工具时保留当前窗口中的输入。

## 六个开发工具

- **JWT**：解析 Header 和 Payload，支持 HS256/384/512 生成及验签，并提示时间声明状态。
- **Base64**：UTF-8 文本编码解码，支持 Base64URL、中文和 Emoji。
- **URL 编码**：支持 URL 参数值与表单参数值的编码解码。
- **日期时间转换**：支持秒/毫秒时间戳、ISO、RFC、UTC、Mongo ObjectID 时间前缀和 Excel 1900 日期序列，可选择本地时区或 UTC。输入留空时按浏览器绘制帧持续刷新，Timestamp 毫秒位和 Excel date/time 小数部分同步跳动；输入具体日期后保持固定。
- **JSON 解析**：支持格式化、压缩、键排序、缩进和转义字符串解析，保留大整数精度；可执行 jq 表达式，例如 `.items[] | select(.active == true) | .name`。计算在本机进行，jq 最多执行 5 秒，输出最多 5000 项、共 4 MiB。
- **JSON Diff**：按路径标记新增、删除和修改，支持只显示差异、交换输入及复制结果；对象忽略键顺序，数组按索引比较。

## 下载与使用

下载下方附件中的 **Floe.exe**，退出正在运行的旧版 Floe 后运行新版即可。此版本为 Windows x64 便携版，无需安装或 Go 运行环境。

可下载 **SHA256SUMS.txt** 校验文件完整性。在 PowerShell 中运行 `Get-FileHash .\Floe.exe -Algorithm SHA256`，与校验文件中的值比较。
