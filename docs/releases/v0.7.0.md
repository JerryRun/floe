## Windows 原生桌面版

- 新增基于 MyGo 的桌面工作区，启动时默认最大化。双击托盘图标可打开或恢复工作区，仍可从托盘菜单在浏览器中打开 WebUI。两种界面共用同一个 Floe Core。
- 桌面工作区提供会话侧栏、双文件面板、传输队列、速查和六种开发工具。文件面板支持双击打开目录或文件，以及交换左右面板。
- 桌面预览支持图片、Markdown、PDF 和视频。PDF 支持鼠标滚轮连续翻页。桌面版可编辑 HTML 源码，网页渲染预览可在 WebUI 中使用。
- 速查支持原地编辑，并在滚动时自动加载前后内容。桌面版和 WebUI 共用目录书签。
- 「关于 Floe」显示构建版本、发布说明和 GitHub 项目链接。

## 下载与使用

下载附件中的 **Floe.exe**，从系统托盘退出旧版后运行新版。此版本为 Windows x64 便携版，无需安装 Go。

可使用 PowerShell 命令 `Get-FileHash .\Floe.exe -Algorithm SHA256` 校验文件，并与 **SHA256SUMS.txt** 中的值比较。
